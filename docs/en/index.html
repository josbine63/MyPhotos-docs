MyPhotos

Manage your iCloud shared albums with ease

💻 macOS ☁️ iCloud 🔄 Auto Sync

Overview

MyPhotos is a macOS application designed to manage your iCloud shared photo albums. It offers advanced features to copy, sync, and manage duplicates in your Photos library.

The application uses a perceptual hash algorithm to detect duplicate photos, even if they have been compressed or slightly modified by iCloud shared albums.

Technologies Used

SwiftUI PhotoKit Swift Concurrency macOS 13+

Copy Shared Albums

This feature allows you to copy photos and videos from iCloud shared albums to your local Photos library. Shared albums are albums you share with other iCloud users or that have been shared with you.

Copy Modes

⚡

Continuous

Copies all selected albums without pausing between each album.

✋

With Confirmation

Asks for confirmation before starting the copy of each album.

Duplicate Detection

During copy, the application automatically detects duplicates using:

  • Creation date and image dimensions
  • Perceptual hash algorithm (16×16 = 256 bits)
  • 5% tolerance on Hamming distance
  • ±2 seconds tolerance on date and ±1 pixel on dimensions

Architecture

The application uses the MVVM (Model-View-ViewModel) pattern with SwiftUI and Swift Concurrency for asynchronous operations.

Perceptual Hash Algorithm

The perceptual hash works as follows:

  1. Resize the image to 256×256 pixels
  2. Sample 16×16 = 256 points
  3. Convert to grayscale
  4. Compare each pixel to the average
  5. Generate a 256-bit binary hash

Two images are considered identical if their Hamming distance is ≤ 5%.

Getting Started

Installation

Clone the GitHub repository and open the project in Xcode 15 or later.

Configure Permissions

On first launch, authorize access to your Photos library in the dialog box.

Select Albums

Choose a feature on the home screen, then select the albums to process.

Click the action button and follow the real-time progress.

Info.plist Configuration

The application requires the following keys in Info.plist:

<key>NSPhotoLibraryUsageDescription</key> <string>MyPhotos needs access to your Photos library to copy shared albums.</string> <key>NSPhotoLibraryAddUsageDescription</key> <string>MyPhotos needs to add photos to your local library.</string>

Frequently Asked Questions

How does duplicate detection work?

The application uses a perceptual hash algorithm that analyzes the visual content of each image. Even if a photo has been compressed or slightly modified, it will be detected as a duplicate if its visual appearance is more than 95% similar.

Are the original photos modified?

No, photos in shared albums are never modified. The application creates local copies in your Photos library. Only duplicate removal affects your local library.

Can I cancel a copy in progress?

In "with confirmation" mode, you can stop the copy between each album. Photos already copied will remain in your library.

What does auto sync do?

It monitors selected albums every 30 seconds and automatically copies new photos to your local library, while avoiding duplicates.

Does the app work on iOS?

Currently, MyPhotos is designed for macOS only. An iOS version could be developed in the future.

Is my data sent anywhere?

No, the application runs entirely locally. Your photos never leave your Mac and no data is sent to external servers.
