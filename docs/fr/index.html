MyPhotos

Gérez vos albums partagés iCloud en toute simplicité

💻 macOS ☁️ iCloud 🔄 Sync Auto

Présentation

MyPhotos est une application macOS conçue pour gérer vos albums photos partagés iCloud. Elle offre des fonctionnalités avancées pour copier, synchroniser et gérer les doublons dans votre bibliothèque Photos.

L'application utilise un algorithme de hash perceptuel pour détecter les photos en double, même si elles ont été compressées ou légèrement modifiées par les albums partagés iCloud.

Technologies utilisées

SwiftUI PhotoKit Swift Concurrency macOS 13+

Copie d'albums partagés

Cette fonctionnalité permet de copier les photos et vidéos des albums partagés iCloud vers votre bibliothèque Photos locale. Les albums partagés sont des albums que vous partagez avec d'autres utilisateurs iCloud ou qui ont été partagés avec vous.

Modes de copie

⚡

Sans interruption

Copie tous les albums sélectionnés sans pause entre chaque album.

✋

Avec confirmation

Demande une confirmation avant de commencer la copie de chaque album.

Détection des doublons

Lors de la copie, l'application détecte automatiquement les doublons en utilisant :

  • La date de création et les dimensions de l'image
  • Un algorithme de hash perceptuel (16×16 = 256 bits)
  • Une tolérance de 5% sur la distance de Hamming
  • Une tolérance de ±2 secondes sur la date et ±1 pixel sur les dimensions

Architecture

L'application utilise le pattern MVVM (Model-View-ViewModel) avec SwiftUI et Swift Concurrency pour les opérations asynchrones.

PhotosManager

Le PhotosManager est la classe centrale qui gère toutes les interactions avec la bibliothèque Photos. Elle est marquée @MainActor et @Observable pour garantir les mises à jour UI sur le thread principal.

Algorithme de hash perceptuel

Le hash perceptuel fonctionne ainsi :

  1. Redimensionne l'image en 256×256 pixels
  2. Échantillonne 16×16 = 256 points
  3. Convertit en niveaux de gris
  4. Compare chaque pixel à la moyenne
  5. Génère un hash binaire de 256 bits

Deux images sont considérées identiques si leur distance de Hamming est ≤ 5%.

Guide de démarrage

Installation

Clonez le dépôt GitHub et ouvrez le projet dans Xcode 15 ou supérieur.

Configuration des permissions

Au premier lancement, autorisez l'accès à votre bibliothèque Photos dans la boîte de dialogue.

Sélectionnez des albums

Choisissez une fonctionnalité sur l'écran d'accueil, puis sélectionnez les albums à traiter.

Lancez l'opération

Cliquez sur le bouton d'action et suivez la progression en temps réel.

Configuration Info.plist

L'application nécessite les clés suivantes dans Info.plist :

<key>NSPhotoLibraryUsageDescription</key> <string>MyPhotos a besoin d'accéder à votre bibliothèque Photos pour copier les albums partagés.</string> <key>NSPhotoLibraryAddUsageDescription</key> <string>MyPhotos a besoin d'ajouter des photos à votre bibliothèque locale.</string>

Questions fréquentes

Comment fonctionne la détection des doublons ?

L'application utilise un algorithme de hash perceptuel qui analyse le contenu visuel de chaque image. Même si une photo a été compressée ou légèrement modifiée, elle sera détectée comme doublon si son apparence visuelle est similaire à plus de 95%.

Les photos originales sont-elles modifiées ?

Non, les photos des albums partagés ne sont jamais modifiées. L'application crée des copies locales dans votre bibliothèque Photos. Seule la suppression des doublons affecte votre bibliothèque locale.

Puis-je annuler une copie en cours ?

En mode "avec confirmation", vous pouvez arrêter la copie entre chaque album. Les photos déjà copiées resteront dans votre bibliothèque.

Que fait la synchronisation automatique ?

Elle surveille les albums sélectionnés toutes les 30 secondes et copie automatiquement les nouvelles photos vers votre bibliothèque locale, tout en évitant les doublons.

L'application fonctionne-t-elle sur iOS ?

Actuellement, MyPhotos est conçu uniquement pour macOS. Une version iOS pourrait être développée dans le futur.

Mes données sont-elles envoyées quelque part ?

Non, l'application fonctionne entièrement en local. Vos photos ne quittent jamais votre Mac et aucune donnée n'est envoyée à des serveurs externes.
